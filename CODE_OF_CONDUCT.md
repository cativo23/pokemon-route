# Code of Conduct

## The short version

Be decent. This is a page about Pokémon games.

## The longer version

Everyone is welcome here regardless of experience, background, identity or which starter they picked.

**Not acceptable:** harassment, personal attacks, slurs, deliberate misgendering, sexualised language or imagery, publishing anyone's private information, or sustained disruption.

**Also not acceptable, and worth naming for this project specifically:** being a jerk about someone's taste in games. Version arguments are the entire point of the route section and they should stay enjoyable. Disagree with the pick, not the person.

## Scope

Applies to issues, pull requests, commits and any other space representing this project.

## Enforcement

Report problems to the maintainer through a GitHub issue or via [cativo.dev](https://cativo.dev). Reports are handled privately. Responses range from a warning to a permanent block, depending on severity, and the maintainer's decision is final.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), trimmed to fit a project of this size.
